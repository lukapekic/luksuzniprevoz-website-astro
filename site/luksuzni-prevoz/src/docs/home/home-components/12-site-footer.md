# SiteFooter — Exact V1 Contract

## Surface
- dark footer background based on page background/surface
- optional subtle top divider only
- no contained rounded outer panel

## Separation from Final CTA
- top margin around section standard

## Desktop inner layout
- main shell
- padding-block: `clamp(2.5rem, 5vw, 4rem)`
- 3 columns
- approximate first column weight `1.2fr 1fr 1fr`
- gap `clamp(2rem, 5vw, 5rem)`

Columns:
1. Brand
2. Services / Company
3. Contact / Hours

## Bottom row
- padding-block about `1.2rem`
- optional subtle top divider
- flex between copyright/legal groups

## Mobile
- one column
- gap around `2rem`
- bottom row stacked

## Data
All links route-derived.
All contact/hours business-data-derived.
Parent company relation may appear quietly.

## Forbidden
newsletter, giant sitemap, oversized social section
