# GoogleReviews — Exact V1 Contract

## Section
- open dark
- standard vertical spacing

## Heading row
Desktop:
- heading left
- compact Google profile CTA right
- gap `space-6`
- margin-bottom `space-8`

Mobile:
- stack heading/CTA

## Desktop presentation
- about 3 cards
- grid gap `space-4`

## Tablet
- about 1.5–2 cards or a 2-card view depending implementation

## Mobile
- swipeable horizontal track
- card width about `min(82vw, 20rem)`
- clear partial-next-card continuation

## Card
- background: surfaceElevated
- radius: `0.75rem`
- padding: about `1.4rem` (map to `space-5/6`)
- min-height about `14rem`
- content stack gap around `space-4`

## Content
- recognizable but restrained rating display
- review excerpt
- reviewer name
- verified metadata only

## Colors
- card text: textPrimary
- metadata: textMuted
- stars/accent: use restrained Google-compatible treatment; do not flood with bright yellow

## No autoplay
External CTA must use verified Google Maps/Business URL.
