# FleetShowcase — Exact V1 Contract

## Section
- open dark
- padding-block: section feature

## Heading row desktop
- flex/grid with heading left and compact CTA right
- align end
- gap: `space-6`
- margin-bottom: `space-8`

Mobile:
- stack heading/CTA
- gap around `space-4`

## Track
- overflow contained to carousel viewport
- item gap: `space-4`

## Card width
Desktop:
- `clamp(18rem, 29vw, 23.5rem)` reference from approved wireframe
- resulting viewport should show ~2.5–3 cards

Tablet:
- tune with container to show ~1.5–2

Mobile:
- `min(82vw, 20rem)` target
- show ~1.1 cards

## Card
- surface contrast: surface or elevated as appropriate
- radius `0.75rem`
- no heavy border/shadow

## Vehicle image
- 16:9 presentation region
- margin around `space-4`
- cutout PNG uses contain
- never cover
- preserve full vehicle

## Meta
- padding inline `space-4`
- padding bottom about `space-5`
- model
- class
- 2–3 verified facts only
- no pricing

## Controls
- no autoplay
- keyboard-operable previous/next
- accessible labels
- disabled/end states meaningful
- reduced motion
