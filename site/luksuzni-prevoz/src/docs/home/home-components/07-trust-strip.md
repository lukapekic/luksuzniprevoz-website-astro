# TrustStrip — Exact V1 Contract

## Section
- open wrapper with standard vertical spacing
- heading margin-bottom: `space-6` / about `1.5rem`

## Contained panel
- background: Theme V2 `surfaceElevated` semantic token
- radius: `1rem`
- padding: `clamp(1.5rem, 3vw, 2.3rem)`

## Desktop >=64rem
- 4 equal columns
- each item min-height about `8.5rem`
- item horizontal padding about `space-6`
- vertical divider between items using divider
- first item no left padding
- last item no divider

## Tablet
- 2x2
- internal dividers form grid
- item padding about `1.4rem`

## Mobile
- single column
- panel padding about `1rem 1.3rem`
- each item padding-block around `1.3rem`
- horizontal dividers only

## Icon
- restrained ~`2rem` footprint
- restrained platinum/accent line treatment only if needed
- decorative icon hidden from AT if title already conveys meaning

## Text
- title H3/small heading
- support 1 concise line target
- primary + muted text colors

## Forbidden
individual cards, counters, statistics, shadows
