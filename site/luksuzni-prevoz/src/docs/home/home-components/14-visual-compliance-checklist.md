# Home Visual Compliance Checklist

Use after initial implementation, before final technical review.

## Header
- [ ] top state works over hero
- [ ] sticky state is compact and stable
- [ ] Book CTA visible desktop/mobile
- [ ] mobile menu full-height and accessible

## Hero
- [ ] image fills full contained panel
- [ ] no separate image column
- [ ] 16:7-ish desktop feel
- [ ] 32–35rem desktop height range unless content needs more
- [ ] 7/5 content-placement grid
- [ ] mobile crop reviewed
- [ ] exactly 2 primary hero CTAs
- [ ] no badges/forms/stats

## Services
- [ ] 35/30/35 mosaic desktop
- [ ] clean rectangular footprint
- [ ] 2x2 tablet
- [ ] 1-column mobile
- [ ] full-card background images
- [ ] no hover lift/scale

## Private Chauffeur
- [ ] open 5/7 desktop
- [ ] no text card/panel
- [ ] 4:3 image
- [ ] package summary is one row, not cards
- [ ] mobile content first

## Trust
- [ ] one elevated contained panel
- [ ] 4 / 2x2 / 1 responsive
- [ ] no individual cards

## Fleet
- [ ] ~2.5–3 cards desktop
- [ ] ~1.5–2 tablet
- [ ] ~1.1 mobile
- [ ] vehicle PNGs contain
- [ ] no autoplay
- [ ] no prices

## How It Works
- [ ] only intentional light Home section
- [ ] 3 steps
- [ ] no cards/icons by default
- [ ] 01/02/03 visible but restrained

## Reviews
- [ ] open dark section
- [ ] elevated cards
- [ ] about 3 visible desktop
- [ ] swipe mobile
- [ ] verified external Google URL
- [ ] no invented ratings/reviews

## Final CTA
- [ ] 22–26rem desktop target
- [ ] ~62/38 split
- [ ] S-Class stays within ~35–40% footprint
- [ ] restrained gradient
- [ ] not second-hero sized
- [ ] no glow/hard image edge

## Footer
- [ ] compact 3-column desktop
- [ ] stacked mobile
- [ ] no newsletter/social bloat
